# Choose your engine

Misty doesn't have its own AI. Your agents run on an engine you already use, such as Claude Code or Codex. Each engine runs on your computer under your own sign-in.

Misty never charges for AI. You pay the engine's maker, if anything, on your own plan.

## Engines you can use

These four are the easiest to start with:

| Engine | What you need | What it costs |
| --- | --- | --- |
| Claude Code | A Claude plan from Anthropic | Your Claude plan |
| Codex | A ChatGPT account from OpenAI | Your ChatGPT plan |
| Antigravity | A Google account | Free |
| OpenCode | Nothing | Free |

Misty also works with Gemini CLI, Qwen Code, Kimi CLI, Grok CLI, MiniMax Code, Qoder CLI, CodeBuddy, Pi, Oh My Pi, DeepSeek Harness and Hermes Agent.

## Set up an engine

Setup asks you to pick an engine the first time you sign in. To add another one later:

1. Open **Agents** from the sidebar and go to **CLIs**.
2. Find the engine you want.
3. Select **Install**, then **Sign in to** the engine. Each engine signs in on its maker's own page.
4. Wait until the engine shows **Ready**. If it doesn't, select **Check again**.

## Change your default engine

Your default engine is the one Misty uses for its own work, such as the Lab, Tutor and reading web pages. It also starts new chats.

1. Open **Settings** and go to **Agents**, then **Engine**.
2. Choose an engine under **Default engine**.

> Not every engine can be the default. It needs to handle images, Misty's tools and web search. Engines that can't show **Can't run Misty's own work**.

## Good to know

- Engine sign-ins stay on your computer. Misty's servers never see them.
- Each computer has its own sign-ins. Set up your engines on every computer you use.
- You can pick a different agent, on any engine, for any chat. See [Agent chats](#/features/chats).
