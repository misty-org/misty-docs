# Connect to a server

Your Misty account lives on a server. You can use Misty Cloud, which we run, or a server you run yourself.

## Use Misty Cloud

Misty Cloud is free, with nothing to set up.

1. Open Misty and select **Get started**, or **Sign in** if you already have an account.
2. Select **Continue with Misty Cloud**.
3. Enter your email and password, or continue with Google.

For more storage, see [Plans](#/account/plans).

## Use your own server

1. Open Misty and select **Get started** or **Sign in**.
2. Select **Use my own server**.
3. Enter the **Server address**, such as `misty.example.com`, and select **Continue**.
4. Sign in, or create an account. On a new server, the first account you create owns the server.

To run a server, see [Set up a server](#/self-hosting/set-up-a-server).

## Use a sign-in link

A sign-in link signs you in without a password. Use one if you forgot your password, or if the person who runs your server sent you one.

1. To get a link for Misty Cloud, go to [Sign in](https://mistysys.com/sign-in) on the Misty website and ask for one.
2. Open the link and choose to open it in Misty.
3. Or, in the app, select **Use a sign-in link** and paste it.

> A sign-in link works once and lasts seven days. Keep it private, like a password.

## Use Misty on another computer

- Install Misty and sign in with the same account.
- Your spaces live on the server, so you'll see the same ones on every computer.
- Engine sign-ins stay on each computer. Set up your engines again on the new one.
