# Agents page

The Agents page is where you manage your agents and what they can use. Open it by selecting **Agents** in the sidebar.

It has three groups of pages:

- **Agents**: your agents and templates to start new ones from.
- **Engines**: the AI tools your agents run on, such as Claude Code and Codex. Go to **CLIs** to install them.
- **Tools**: plugins, skills, prompts, MCP servers and apps your agents can use.

## Create an agent

1. Go to **Your agents**.
2. Under **New agent**, choose an **Engine**, such as Claude Code.
3. Enter a **Name** and choose the **Folder** it works in.
4. Select **Create agent**.

To change an agent's name, role or instructions later, open it and select **Save changes** when you're done.

## Connect an app

Apps let your agents work in tools like Notion, Linear or Figma. You sign in on the app maker's own page. Misty never sees your password.

1. Go to **Apps**.
2. Search under **Find an app**.
3. Select **Connect** next to the app.
4. Sign in to the app in your browser, then come back to Misty.

- Every agent can use the apps you connect.
- To disconnect, select the check mark next to the app and choose **Disconnect**.
- If you use Claude Code, apps you connected on claude.ai appear under **Claude Code apps**.

> Your agent asks before it acts in an app. See [Approve actions](#/features/chats).

## Add a skill

A skill teaches an agent how to do a specific kind of task.

1. Go to **Plugins** and choose an agent's engine.
2. Open **Skills** and select **Browse skills**.
3. Select **Install** next to the skill you want.

To add a skill from a folder on your computer, go to **Skills** and select **Import local skill**.

## Install a plugin

A plugin can add several skills and apps at once.

1. Go to **Plugins** and choose an engine.
2. Find the plugin. Filter by **Installed** to see what you already have.
3. Select **Install**. Some plugins ask you to sign in to an app too.

To remove a plugin, open its menu and choose **Remove**. To add plugins from another source, select **Add a marketplace**.
