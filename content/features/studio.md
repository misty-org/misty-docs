# Studio

The Studio is a 3D room where your agents work. Each agent has a desk. Agents type while they work and wave at the door when they need you.

You can see your teammates' agents there too, while those teammates are in the same space.

## Open the Studio

1. In the sidebar, select **More**.
2. Select **Studio**.

To keep it in the sidebar, right-click **More**, choose **Reorder pins** and pin **Studio**. You can also search for Studio with Cmd+K (Ctrl+K on Windows and Linux).

## See what your agents are doing

The toolbar at the bottom of the room has three modes. **Studio** (key 1) shows the **Team** panel, which sorts your agents into:

- **Needs you**: waiting for your answer or approval.
- **Working**: running a task now.
- **Finished**: done, with results to review.
- **Free**: ready for a new task.

Requests waiting for you are listed under **Requests**.

## Talk to an agent

1. Select an agent at its desk.
2. Type a message and select **Send**.
3. To keep going in a full chat, select **Open chat**.

You can also type in the box at the bottom of the room. Start with @ and the agent's name, then say what you'd like.

## Hire an agent

Hiring adds a new agent with its own desk.

1. Select **Hire** in the toolbar (key 2).
2. Choose its engine, such as Claude Code or Codex. Engines you haven't installed are locked. See [Choose your engine](#/getting-started/choose-engine).
3. Enter a **Name**, a **Role** and the **Folder** it works in.
4. Select **Hire**.

To change an agent's name, role or look later, select it and choose **Customize**.

## Arrange the room

1. Select **Build** in the toolbar (key 3).
2. Change the **Room size**, add **Furniture**, or set **Whose desk** each desk is.
3. Use **Turn** and **Remove** to move things. **Reset layout** starts over.

## Walk around

- Press V to switch between the overview camera and walking.
- While walking, use W, A, S and D to move, and drag to look around.
- Near an agent, press E to talk to it. Near a free desk, press E to hire.

> If your computer's graphics can't draw the room, the Studio shows a message instead. Your agents still work as usual on the Agents page.
